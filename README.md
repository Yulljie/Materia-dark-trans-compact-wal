# Materia-dark-trans-compact-wal

A modified GTK theme based on [materia-theme](https://github.com/nana-4/materia-theme) featuring translucent background and dynamic color.

## Usage

1. Copy the theme folder to `/usr/share/themes/`.
2. Apply the theme to your GTK applications using your preferred customization tool.

**Note:** This theme is designed to work with the [wallpaper.sh](https://codeberg.org/Yulliil/My_Artix_Configuration/src/branch/main/sway/scripts/wallpaper.sh) script and the [Materia-dark-trans-compact-wal-color.css](https://codeberg.org/Yulliil/My_Artix_Configuration/src/branch/main/wal/templates/Materia-dark-trans-compact-wal-color.css) wal template. The script sets your wallpaper, generates a color scheme for the theme and performs other tasks (please refer to the script for details).

> [!IMPORTANT]
> The script contains **hardcoded file paths and display outputs**. You will need to manually adjust it to match your own system configuration.
