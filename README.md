# Materia-dark-trans-compact-wal

A modified GTK theme based on [materia-theme](https://github.com/nana-4/materia-theme).

## Usage

1. Copy the theme folder to `/usr/share/themes/`.
2. Apply the theme to your GTK applications using your preferred customization tool.

**Note:** This theme is designed to work with the [wallpaper.sh](https://codeberg.org/Yulliil/My_Arch_Configration/src/branch/main/sway/scripts/wallpaper.sh) script. The script sets your wallpaper and generates a color scheme for the theme based on the image colors. 

> [!IMPORTANT]
> The script contains **hardcoded file paths and display outputs**. You will need to manually adjust it to match your own system configuration.
